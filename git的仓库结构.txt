# 🐳 FatFish-Whisper (潜鱼潜语)

**"给大肥鱼一个‘我想’的灵魂之所。"**

一个轻量化、可拔插的 Bot 潜意识（Inner OS）与情绪挂载引擎。

## 核心功能
把情绪判定移交给本地情趣判极，状态级根据各项数据后生成建议还给大模型。


## 🏗️ 架构设计
- **Adapter (插件端)**：部署在宿主 Bot 侧，负责防抖合并、动作执行、撤回冷却拦截。
- **Core-Engine (情绪机)**：独立微服务，运行双轨判定、内心OS生成、Prompt拼装。
- **记忆路由**：优先借用宿主原生记忆，支持挂载外部插件（Mem0），本地 LRU 兜底。

    exit /b

from sqlalchemy.orm import declarative_base
import datetime

Base = declarative_base()

class UserState(Base):
    __tablename__ = "user_states"
    user_id = Column(String, primary_key=True, index=True)
    affinity_raw = Column(Integer, default=50)   # 好感度，可突破100
    emotion_current = Column(Integer, default=50) # 当前情绪值 0-100
    emotion_level = Column(String, default="L0")  # L0/L1/L2/CRISIS
    last_update = Column(DateTime, default=datetime.datetime.utcnow)

class TokenLog(Base):
    __tablename__ = "token_logs"
    id = Column(Integer, primary_key=True, autoincrement=True)
    user_id = Column(String)
